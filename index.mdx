The GBM Plus API Python library gives developers programmatic access to the GBM Plus and Homebroker trading platform. With a single import you can authenticate, inspect your strategies, submit buy/sell orders for Mexican and US market instruments, and move funds between accounts.

<Warning>
  This is an unofficial, community-built library. The GBM Plus API is not publicly documented and was reverse-engineered. Review the [GBM Terms of Service](https://invertir.gbm.com/condiciones-del-servicio-gbmplus) before use. You assume full responsibility for compliance.
</Warning>

## Getting started in three steps

<Steps>
  <Step title="Install via pip">
    ```bash
    pip install gbmplus
    ```
  </Step>
  <Step title="Set your credentials">
    Export your GBM+ email, password, and client ID as environment variables. Find your `CLIENT_ID` in the GBM+ login dashboard.

    ```bash
    export USER_EMAIL="you@example.com"
    export USER_PASSWORD="your-password"
    export CLIENT_ID="your-client-id"
    ```
  </Step>
  <Step title="Make your first call">
    ```python
    import gbmplus

    gbm = gbmplus.GBMPlusAPI(output_log=False)
    accounts = gbm.accounts.getAccounts()
    print(accounts)
    ```
  </Step>
</Steps>

  See the [Configuration guide](/guides/configuration) for all available session parameters including timeouts, retry behaviour, and logging options.
</Tip>
